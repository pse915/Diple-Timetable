# Diple Timetable — Windows 로컬 오프라인 초기 버전

> **중요: 이 프로젝트는 기존 운영 앱의 모든 기능을 이식한 완성본이 아닙니다.**
> 엑셀 우선, PC 단독 사용으로 전환한 **실행 가능한 핵심 기능 프로토타입**입니다. 실제 학교 운영 전 추가 검증과 원본 기능 이식이 필요합니다.

## 기능

- Google Sheets·Apps Script·Streamlit·클라우드 서버 없이 사용
- `.xlsx` 시간표 가져오기: 학교정보, 교사, 학급, 시간표 4개 시트
- 교사별/학급별 시간표 읽기
- 학급별 수업 교과·교사·교실 수정
- 한 학급의 두 수업 교환 및 교사 중복 배정 검사
- 시간표 편집/맞교환의 변경 이력 자동 기록
- 내 PC SQLite에 자동 저장, 엑셀로 내보내기
- 같은 PC에 여러 학교 데이터 분리 저장
- 동일 학교 시트 재업로드 전 확인 + 로컬 DB 자동 백업
- Windows GitHub Actions에서 PyInstaller 단일 EXE로 자동 빌드

## 원본 프로젝트와의 관계

참조 원본은 별도로 보존하며 이 배포 패키지에는 특정 학교의 이름, URL, 관리자 계정, 학교 데이터가 포함되지 않습니다.

- 이 새 프로젝트는 **원본 GitHub 브랜치나 배포 중인 Streamlit 프로그램을 건드리지 않습니다**.
- 기존 React UI 및 Python 7,069줄 원본 업무 엔진은 작업 환경에 전체 소스가 없어 **이식되지 않았습니다**. 현재는 별도 Tkinter UI, 독립 로컬 로직을 사용합니다.
- 수업 교환은 **기초적인 교사 중복 배정 검사만 적용**되어 있습니다. 원본 교체 추천/제약/승인/이력 복원 로직과 완전히 동일하지 않습니다.
- NEIS, Gemini, 전체 관리자 기능, 업로드 자동 인식, 원본 엑셀 다중 스키마, 네트워크 다중 사용자 기능은 아직 포함되지 않았습니다.
- 데스크톱 단독 로컬 앱이므로 로그인/계정 기능을 제공하지 않습니다. 학교 공유 PC의 계정 접근권한과 파일 백업에 유의하세요.

## Python으로 실행

Windows 10/11 권장. Python 3.12 설치 후 다음을 실행합니다.

```powershell
cd Diple-Timetable-Desktop-Local
python main.py
```

Python 표준 라이브러리만 사용합니다. **실행 자체에는 pip 패키지가 필요하지 않습니다.** (Python 설치 시 Tkinter 포함 필요)

## Windows EXE 만들기

### 방법 A — GitHub에서 자동으로 EXE 생성 (Windows PC에 Python 없어도 가능)

1. GitHub에서 **새 저장소**를 만듭니다. 기존 운영 앱의 저장소 및 배포 브랜치는 수정하지 마세요.
2. 본 ZIP 압축을 풀어 **내용물 전체**를 새 저장소 최상위에 업로드합니다. `.github/workflows/build-windows.yml`도 포함합니다.
3. GitHub 저장소의 **Actions** 탭에서 `Build Diple Timetable Windows EXE`를 선택한 후 **Run workflow**를 클릭합니다.
4. 빌드가 통과하면 해당 실행의 **Artifacts**에서 `Diple-Timetable-Windows`를 내려받아 압축을 해제합니다.
5. 생성된 `Diple-Timetable.exe`를 Windows PC에서 실행합니다.

*GitHub Actions 사용은 GitHub 계정의 권한, 정책, 사용량 제한에 따릅니다. EXE 자동 생성은 Windows 러너에서 진행되며, 이 실행 환경에서는 실제 빌드 결과가 검증되지 않았습니다.*

### 방법 B — Windows PC에서 직접 빌드

```powershell
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

산출물: `dist\Diple-Timetable.exe`

## 엑셀 형식

포함 파일: `templates/학교_시간표_양식.xlsx`

| 시트명 | 필수 열 | 내용 |
| --- | --- | --- |
| 학교정보 | 학교명, 학년도 | 첫 데이터 행에 학교/연도 |
| 교사 | 교사명, 담당교과 | 중복되지 않는 교사 목록 |
| 학급 | 학급 | `1-1`과 같은 학급 목록 |
| 시간표 | 학급, 요일, 교시, 교과, 교사, 교실 | 수업별 1행 |

요일: 월/화/수/목/금/토/일. 교시: 1~12.

**원본 Streamlit용 엑셀 파일이나 NEIS 다운로드 형식을 바로 지원하는 것은 아닙니다.** 처음에는 템플릿 형식에 맞춰 변환해야 합니다.

## 사용 방법

1. EXE 실행 → **예시 템플릿 저장** 클릭.
2. 엑셀의 `학교정보!A2`에 실제 학교명을 입력하고, 학년도·교사·학급·시간표를 학교에 맞게 수정해 저장.
3. **엑셀 불러오기** 클릭 → 내용 미리 검증한 뒤 가져오기 확인.
4. **학급별** 또는 **교사별** 조회.
5. 학급별 조회에서 수업 칸 선택 후 **수업 편집**. 두 칸을 선택한 뒤 **맞교환**.
6. 변경 내용은 자동 저장됨. **엑셀 내보내기**로 현재 상태와 변경 이력을 기록.

## 데이터 저장 및 주의

- 로컬 데이터 폴더: `%LOCALAPPDATA%\SchoolTimetableDesktop\schools\...\data.sqlite3`
- 자동 백업 폴더: `%LOCALAPPDATA%\SchoolTimetableDesktop\backups\`
- 백업은 **기존 학교 엑셀 데이터를 다시 가져올 때** 자동 생성됩니다. PC 파손에 대비한 정기 외부 백업은 사용자가 별도로 수행해야 합니다.
- 작업용 PC 한 대에서만 동작합니다. 여러 PC 간 실시간 동기화 기능이 없습니다.
- Excel 형식을 단순화하기 위해 내보낼 때 원본 서식, 수식, 병합 셀, 그림은 유지되지 않습니다.
- 학교 실제 정보 대신 가상의 예시 데이터를 포함합니다.
- 서명되지 않은 EXE는 Windows SmartScreen 또는 기관 보안 정책에 의해 실행이 제한될 수 있습니다.

## 개발 상태

- `python -m unittest discover -s tests -v`: 자동 테스트
- Windows EXE 생성: GitHub Actions / Windows PyInstaller
- 최초 작성은 Linux 테스트 환경. **이곳에서는 Windows EXE 자체를 직접 빌드·실행하지 못합니다.**

## 향후 본격 이식 단계

1. 원본 GitHub 저장소 ZIP 확보 → 모든 메뉴/교체 규칙 추출
2. 원본 Python 엔진 포팅과 결과 동일성 테스트
3. 기존 엑셀 파일 자동 인식과 학교별 설치 마법사
4. 고급 맞교환·추천·승인·이력 복원 및 업무 기능 구현
5. Windows EXE 실기기 검증 → 학교 파일 기반 파일럿

## 범용 배포 및 기존 로컬 데이터 안내

- 이 배포본에는 어떤 특정 학교명이나 특정 학교의 URL도 사전 설정하지 않았습니다. 학교명은 엑셀 양식에서 직접 입력합니다.
- 앱 내부 저장 폴더 이름이 범용 명칭으로 변경되었습니다. 이전 시제품에서 이미 저장한 데이터는 자동 연결되지 않으며, 이전 시제품의 엑셀 내보내기를 이용해 새 앱으로 가져오세요.
- 기존 운영 서비스와 그 데이터에는 변경을 가하지 않습니다.
